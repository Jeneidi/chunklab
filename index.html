06 / method

          
The benchmark stays reproducible

        

        
Every strategy shares the corpus, questions, retriever, and metrics. Chunking is the variable.

      

      

        

          
Method

          
The committed run uses Okapi BM25 with k1 = 1.2 and b = 0.75. Tokens are lowercase alphanumerics split on every other character, with no stemming. A query is a hit when any returned context contains a case-insensitive, whitespace-normalized SQuAD gold answer string.

        

        
    
          
  1. Hold the data constant
    SQuAD v1.1 dev paragraphs are grouped back into source articles. Seed 20260729 selects 40 articles and 800 labeled questions.
    2. 
          
  2. Split the corpus eight ways
    Fixed, recursive, sentence-window, parent-document, semantic proxy, and fixed 1,000-character strategies each index their own chunks.
    3. 
          
  3. Rank and score
    Recall@k, MRR@10, nDCG@10, and context cost quantify retrieval quality and the context needed to clear 90% recall.
    4. 
        

      

      

        

          
Data

          
SQuAD v1.1 dev paragraphs are grouped back into source articles. The offline builder downloads the source file when it is absent and ranks indexed chunks locally with BM25.

        

        

          
Limitations

          
String containment misses semantic equivalents, BM25 is lexical, and the optional live embedding run answers a different retrieval question. Results do not transfer blindly to another corpus.

        

        

          
Reproduce

          
python3 scripts/build_benchmark.py
node app.js --selftest
